## Historical material

Phase reports, architecture freezes, source-of-truth matrices, build guides and
specifications in this tree describe decisions made while the combined system
was being assembled. They are retained for provenance and are superseded by the
canonical documents above whenever they disagree. Retired standalone projects
and historical uploads are under
[`../archive/provenance/`](../archive/provenance/).

No number in this index is a measurement claim. Every measured number lives in
the generated evaluation document and carries a conditioned claims-ledger row.
VoiceGuard / MAYA remains frozen and is not part of this release.
